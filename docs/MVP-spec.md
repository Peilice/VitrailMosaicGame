# 琉璃嵌畫 MVP 規格

本文件記錄訪談中已定案的決定。願景與完整構想見 `初步規劃.md`，詞彙定義見 `GLOSSARY.md`。

## 1. 範圍

- 平台：Web，桌面加手機平板，滑鼠與觸控共用一套 Pointer Events。
- MVP 內容：單一關卡、休閒模式（不旋轉）、拖曳、磁吸、卡入、發光、完成動畫。
- 開發者：獨立開發。玻璃紋理用程式生成，音效用 CC0 素材。

### 延後清單

- 挑戰模式的旋轉（預留設計：觸控為選中玻璃後點旋轉按鈕；桌面為選中玻璃時滾輪旋轉，未選中時滾輪縮放）
- 透光提示
- 大教堂或溫室的進度介面
- 托盤排序
- BGM
- 多關卡進度
- PWA
- Steam 版
- 從任意圖片自動切割

## 2. 手感規則

### 手勢

- 單指按在玻璃上：拖曳該玻璃。
- 單指按在空白處：平移畫面。
- 雙指：縮放加平移。
- 桌面：左鍵拖曳，滾輪縮放。

### 放置判定

- 每片玻璃只對應自己的唯一格子，形狀或顏色相同也不互換。
- 磁吸半徑約為該片尺寸的 0.5 倍（可調）。
- 在半徑內放開：卡入並發光，之後鎖死。
- 在半徑外放開：留在放開位置，不彈回托盤，沒有懲罰。
- 放到另一個格子的磁吸半徑內：發出沉悶聲並輕微彈開。
- 沒有計時、分數、錯誤計數。

### 版面

- 橫向或寬螢幕：側邊托盤，主框約 70%。
- 直向螢幕：底部托盤，可橫向捲動，主框約 70%。
- 托盤內玻璃縮小顯示，拖出時放大到格子的比例。
- 依長寬比自動切換版面。
- 托盤順序固定隨機（以種子決定），排序延後。

## 3. 資料與渲染

### 關卡資料

- SVG 約定：每個 `<path>` 是一片玻璃；`fill` 為基礎色；`data-texture` 指定紋理（ripple、bubble、crackle）；`id` 為片 id。
- 鉛條不另外畫，由輪廓自動描邊，粗細為全域參數。
- 腳本把曲線攤平成多邊形，輸出 JSON：`{ id, polygon[], color, texture, centroid }`。
- 格子形狀等於玻璃形狀，不存兩份。
- 命中測試使用點在多邊形內的演算法，凸與凹皆可。

### 渲染

- 技術：TypeScript、Vite、PixiJS（WebGL）。
- 支援目標：近兩年的 iOS Safari 與 Android Chrome。
- 所有玻璃共用一支 fragment shader，以 uniform 控制基底色、紋理、亮度。
- 未拼上：降低飽和度與亮度。拼上後：漸亮並在鉛條內側加柔光。
- bloom 預設關閉，經幀率偵測確認效能足夠才開啟。
- 完成動畫：光掃過畫面，全部玻璃亮到最大，背景投射模糊放大的彩色倒影，約 3 至 4 秒，結束後停留在最終畫面，可重玩。

## 4. 音效與存檔

### 音效

- 三個核心音效：拾起、放錯、鑲嵌（CC0 素材）。
- 不做 BGM。
- 首次觸碰時解鎖 AudioContext。
- 唯一的常駐 UI 是右上角靜音鈕。
- 音效總量小於 200KB，預先載入。

### 存檔

- localStorage 存已鑲嵌的片 id、托盤種子、完成旗標，附 `version: 1`。
- 重新整理後回到上次進度，托盤順序不變。
- 完成後可重玩，重玩會清除該關進度。
- 版本不符時重置，不載入壞資料。
- localStorage 不可用時退回記憶體狀態，不顯示錯誤。

## 5. 工程

### 結構

- `src/core/`：純邏輯（幾何、命中測試、磁吸、存檔、關卡型別），不依賴 PixiJS 與 DOM。
- `src/render/`：PixiJS 場景、shader、動畫。
- `src/input/`：Pointer Events 手勢。
- `src/audio/`：音效載入與播放。
- `tools/svg-to-level.ts`：SVG 轉 JSON 腳本。
- `levels/*.svg`：來源。
- `public/levels/*.json`：建置產物，兩者都進 git。

### 工具

- pnpm、TypeScript、Vite、Vitest、ESLint、Prettier，並以 `tsc --noEmit` 做型別檢查。
- 暫不設定 CI。

### 部署

- 第一個目標為 GitHub Pages。
- Vite `base` 設為 `./`，`dist` 打包成 zip 即可上傳 itch.io。
- 只有 push 到 `main` 才觸發發佈。
- 不做自訂網域、分析工具或使用者資料收集。

## 6. 第一個關卡

- 左右對稱的蝴蝶，約 15 片，玻璃大小不一，顏色對比強烈。
- 背景也切成玻璃片，整個窗框是完整的彩繪窗。
- 由開發者在 Inkscape 或 Figma 繪製 SVG。
- 150 片壓力測試關卡用腳本隨機生成 Voronoi 分割。

## 7. 驗收

- `src/core/` 用 Vitest 單元測試（命中測試、磁吸、幾何、存檔、SVG 轉換）。
- 渲染與手勢以手動驗收。
- 效能：
  - 20 片關卡在中階手機（近 3 至 4 年的 Android 機種或 iPhone）維持 60fps。
  - 150 片壓力關卡至少 30fps。
- 手感：開發者與 2 至 3 位朋友在手機上完整玩過一次，沒人需要說明就會玩，且至少一半人覺得「卡進去那下很舒服」。
